# Action Reference

Every built-in action a tale can call, generated from the action scripts in `addons/storyteller/actions/` by `addons/storyteller/editor/action_reference.gd`. Do not edit this file by hand; change the action's `##` comment and run `addons/storyteller/editor/write_action_reference.gd`.

Arguments can be given by position or by name: `backdrop("night", time = 2.0)`. Actions that take time can be awaited, `await wait(1.0)`, to hold the tale until they finish. Cast member and camera methods are listed in §13 of the [TaleScript specification](talescript-spec.md).

Actions: [`ambience`](#ambience), [`ask_number`](#ask-number), [`ask_text`](#ask-text), [`autosave`](#autosave), [`backdrop`](#backdrop), [`cg`](#cg), [`clear_page`](#clear-page), [`clear_props`](#clear-props), [`collect`](#collect), [`dialogue_style`](#dialogue-style), [`emit`](#emit), [`exit_all`](#exit-all), [`fade_in`](#fade-in), [`fade_out`](#fade-out), [`filter`](#filter), [`flash`](#flash), [`hide_cg`](#hide-cg), [`hide_dialogue`](#hide-dialogue), [`hide_prop`](#hide-prop), [`music`](#music), [`play_movie`](#play-movie), [`prop`](#prop), [`shake`](#shake), [`sound`](#sound), [`stop_ambience`](#stop-ambience), [`stop_audio`](#stop-audio), [`stop_music`](#stop-music), [`voice`](#voice), [`wait`](#wait), [`weather`](#weather).

## ambience

```gdscript
ambience(name, volume = 1.0, fade = 1.0)
```

Plays a looping background sound (rain, crowd noise) from the ambience folder.

| Parameter | Type | Default |
|---|---|---|
| `name` | String | required |
| `volume` | float | `1.0` |
| `fade` | float | `1.0` |

## ask_number

```gdscript
ask_number(prompt, default = 0, min = 0, max = 100)
```

Asks the player for a whole number. Use with await to get the answer.

| Parameter | Type | Default |
|---|---|---|
| `prompt` | String | required |
| `default` | int | `0` |
| `min` | int | `0` |
| `max` | int | `100` |

## ask_text

```gdscript
ask_text(prompt, default = "", max_length = 24)
```

Asks the player to type something. Use with await to get the answer:

```gdscript
player_name = await ask_text("What's your name?", "Sam")
```

| Parameter | Type | Default |
|---|---|---|
| `prompt` | String | required |
| `default` | String | `""` |
| `max_length` | int | `24` |

## autosave

```gdscript
autosave()
```

Saves to the autosave slot, for example at the start of a chapter.

## backdrop

```gdscript
backdrop(name, transition = "fade", time = 1.0, mask = "")
```

Shows a backdrop image from the backdrop folder, or a Color such as Color.BLACK. Color.TRANSPARENT removes the backdrop and shows the game behind it. Transitions: none, fade, dissolve, wipe_left/right/up/down, slide_left/right/up/down, and any `StoryTransition` the project adds. `mask` names a grayscale image in the transition folder for "dissolve".

| Parameter | Type | Default |
|---|---|---|
| `name` | any | required |
| `transition` | String | `"fade"` |
| `time` | float | `1.0` |
| `mask` | String | `""` |

## cg

```gdscript
cg(name, variant = "", transition = "fade", time = 1.0)
```

Shows a CG, a full-screen event picture from the CG folder, over the stage. A CG folder holds one image per variant; variant picks one ("" shows "default" or the first). Showing a CG unlocks its gallery entry. Transitions are the same as for backdrop().

| Parameter | Type | Default |
|---|---|---|
| `name` | String | required |
| `variant` | String | `""` |
| `transition` | String | `"fade"` |
| `time` | float | `1.0` |

## filter

```gdscript
filter(name, strength = 1.0, time = 0.5)
```

Recolors the stage with "grayscale", "sepia", "night", "warm", or "cold", softens it with "blur", or darkens its edges with "vignette". filter("none") removes it. The dialogue box and menus keep their colors.

| Parameter | Type | Default |
|---|---|---|
| `name` | String | required |
| `strength` | float | `1.0` |
| `time` | float | `0.5` |
