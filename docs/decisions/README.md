# Decision Records

Each file records one significant design decision, the reasoning behind it, and the alternatives considered. Together they document how StoryTeller was designed independently.

To add one, copy `0000-template.md`, use the next number, and include it in the pull request that implements the decision. Accepted records are not rewritten; a later record supersedes them instead.
