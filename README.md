# StoryTeller

A visual novel and interactive story framework for Godot.

Writers create stories in TaleScript, a small language that looks and feels like GDScript. StoryTeller handles characters, scenery, dialogue, choices, audio, saving, localization, and menus.

> **Status:** early development (milestone M3 complete). The language, runtime, Story editor tab, characters, backdrops, transitions, camera, audio, saves, rewind, history, settings, and the menu set work. Effects, localization, and the visual editor are still to come.

## Requirements

- Godot **4.7.2** (standard build; .NET is not required)

## Getting the project running

1. Clone this repository.
2. Open `project.godot` in Godot 4.7.2. The StoryTeller plugin is already enabled.
3. Run the tests:
   - Windows: `.\tools\run_tests.ps1 -Godot D:\Godot` (the folder that holds the Godot console executable)
   - Linux and macOS: `GODOT_BIN=/path/to/godot tools/run_tests.sh`

## Try the demo

Press **Play** in the Godot editor. The demo opens on its title screen; **New Game** plays `demo/tales/welcome.tale`, a short tour that ends with the sample scene from the project plan. All demo art and music are generated by `tools/demo_assets/generate.py`.

| Input | Action |
|---|---|
| Space, Enter, or click | Continue |
| Hold Ctrl | Skip |
| A | Toggle auto mode |
| Escape or right click | Pause menu (save, load, history, settings) |
| H | History |
| Page Up or mouse wheel up | Rewind |
| F5 / F9 | Quick save / quick load |

The buttons along the dialogue box do the same things. Bindings are Godot input actions named `story_*`; change them in **Project Settings > Input Map**.

## Writing a tale

Create a file ending in `.tale` (by default in `res://story/tales/`):

```gdscript
var visits := 0

beat start:
	backdrop("library", transition = "fade")
	music("library_theme", volume = 0.6)
	ada.enter("smile", at = CENTER)
	visits += 1
	ada: "Welcome back. Visit number {visits}."
	choose:
		"Stay":
			jump start
		"Leave":
			ada (neutral): "Goodbye."
			ada.exit()
```

Characters, backdrops, and audio are found by name in `res://story/` (see the [asset folders](docs/talescript-spec.md#134-asset-folders)).

Edit tales in the **Story** tab at the top of the Godot editor. It highlights TaleScript and lists problems as you type; Ctrl+S saves and reimports.

Then play it from game code:

```gdscript
await Story.play("my_tale")
```

Or let StoryTeller run the whole game: set **Start Tale** and **Game Title** in your `StoryConfig` and call `Story.show_title()` from the main scene. New Game, Continue, saving, loading, and settings then work without more code.

Tales can ask the player for input and change the dialogue style:

```gdscript
player_name = await ask_text("What's your name?", "Sam")
dialogue_style("page")    # lines collect on a full page, like a book
```

The full language reference is in [docs/talescript-spec.md](docs/talescript-spec.md).

## Exporting

Export with Godot's usual **Project > Export**. To check that a project still finds its cast, moods, and tales once exported (no export templates needed):

```
GODOT_BIN=/path/to/godot tools/check_export.sh
```

CI runs this check on every pull request.
